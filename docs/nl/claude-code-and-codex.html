Claude Code en Codex, als team. Zonder terminal.

Claude Code en Codex zijn krachtige AI-codeeragents, gemaakt voor de terminal. Coodoo laat ze voor je samenwerken, met doelen, een autopilot, reviews, GitHub en veiligheidsregels eromheen.

Wat Coodoo toevoegt

Op zichzelf wachten de agents in een terminal op je volgende opdracht, en regel je Git, testen en veiligheid zelf. Coodoo maakt er een team van waarmee je in gewone woorden praat.

  • Een chat in gewone woorden in plaats van terminalopdrachten
  • Twee agents die elkaars werk controleren
  • Een autopilot die doelen en taken afwerkt
  • Branches, pull requests en releases, geregeld
  • Veiligheidsregels die altijd aanstaan

Niet inbegrepen: je AI-abonnement

Coodoo is niet gemaakt door Anthropic of OpenAI en bevat hun diensten niet. Je gebruikt je eigen abonnement bij Anthropic (Claude) en/of OpenAI (ChatGPT), onder hun voorwaarden.

Veelgestelde vragen

Is Coodoo gemaakt door Anthropic of OpenAI?

Nee. Coodoo is gemaakt door CentreBrain en is niet verbonden aan Anthropic of OpenAI.

Welk abonnement heb ik nodig?

Claude (Pro of Max) voor Claude Code en/of ChatGPT (Plus of Pro) voor Codex. Eén is genoeg; met beide bouwt de een en reviewt de ander.

Kan ik Claude Code en Codex nog zelf gebruiken?

Ja. Coodoo gebruikt de gewone programma’s, dus je kunt ze ook gewoon in je eigen terminal blijven gebruiken.
