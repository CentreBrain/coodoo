Netjes op GitHub. Niets komt ongetest op main.

Coodoo werkt met Git en GitHub zoals een professioneel team dat doet, zodat jij dat niet hoeft: elk doel op een eigen branch, opgeleverd op development, en via controles die jij kiest naar staging en main.

Download Coodoo Bekijk de prijs

Jouw flow, elke keer gevolgd

Je kiest de branches waar je werk doorheen gaat, bijvoorbeeld development → staging → main. Coodoo slaat nooit een stap over, opent pull requests waar een branch beschermd is, en houdt alles in je eigen GitHub-account.

  • Elk doel op een eigen branch, die daarna wordt opgeruimd
  • Commits op jouw naam, nooit op naam van de AI
  • Met één klik doorzetten naar de volgende branch
  • Releases met een changelog in gewone woorden

Zo werkt het

  1. 1Een doel krijgt een eigen branch.
  2. 2Elke goedgekeurde taak wordt daar op jouw naam gecommit.
  3. 3Het afgeronde doel wordt samengevoegd, getest en gereviewd, en gaat naar development.
  4. 4Jij zet het door naar staging en main, via de controles van je flow.

Geen Git-kennis nodig

Je hoeft niet te weten wat een branch of een merge is. Coodoo legt in gewone woorden uit wat er gebeurt, en vraagt je alleen iets als de beslissing bij jou ligt, bijvoorbeeld voordat iets naar main gaat.

Veelgestelde vragen

Moet ik Git kennen?

Nee. Coodoo regelt branches, commits en pull requests voor je.

Kan ik een bestaande repository gebruiken?

Ja. Open of clone een repository die je al hebt; Coodoo werkt ermee zoals hij is.

Wat als ik op twee computers werk?

Haal het nieuwste werk met één klik op de andere computer op. Een agent controleert eerst beide kanten, zodat er niets verloren gaat.
