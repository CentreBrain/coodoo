Alles binnen Coodoo

Een beetje zoals Docker, maar zonder containers: de programma’s staan in Coodoo’s eigen map, en alleen Coodoo gebruikt ze. De agents, de terminal in Coodoo en je draaiende app krijgen de juiste versie, en je eigen opstelling blijft zoals hij was.

  • Kies versies, zoals PHP 8.4 of Node 22, en een standaard per taal
  • Patches dagelijks gecontroleerd en vanzelf geïnstalleerd
  • Laravel zonder Laravel Herd: PHP en Composer erbij
  • Coodoo’s eigen MySQL en PostgreSQL, met een database per project
  • Laravel Herd en Docker werken gewoon, als je ze gebruikt

Zo werkt het

  1. 1Open een project.
  2. 2Coodoo ziet wat het nodig heeft, aan bestanden zoals package.json of composer.json.
  3. 3Wat ontbreekt, wordt van de officiële bron geïnstalleerd en gecontroleerd.
  4. 4Je app start met de juiste versies, en zijn database staat klaar.

Op Mac en Windows

Het werkt op macOS en Windows. Op Windows heeft PHP de Microsoft Visual C++ Runtime nodig, die op de meeste pc’s al staat; ontbreekt hij, dan zegt Coodoo waar je hem haalt.

Veelgestelde vragen

Verandert Coodoo mijn computer?

Nee. Alles komt in Coodoo’s eigen map en alleen Coodoo gebruikt het. Je PATH en je eigen terminal blijven zoals ze zijn.

Heb ik Laravel Herd of Docker nodig?

Nee. Coodoo installeert PHP, Composer en de databases zelf. Gebruik je Herd of Docker al, dan werkt Coodoo ermee.

Waar komen de programma’s vandaan?

Van vaste, bekende bronnen zoals nodejs.org, Eclipse Temurin, python-build-standalone, static-php-cli, windows.php.net, mysql.com en Maven Central, en elke download wordt gecontroleerd met een controlegetal.
