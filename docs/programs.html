Everything inside Coodoo

A bit like Docker, without the containers: the programs live in Coodoo’s own folder, and only Coodoo uses them. The agents, the terminal in Coodoo and your running app get the right version, and your own setup stays as it was.

  • Choose versions, such as PHP 8.4 or Node 22, and a standard per language
  • Patches checked every day and installed by themselves
  • Laravel without Laravel Herd: PHP and Composer included
  • Coodoo’s own MySQL and PostgreSQL, with a database for each project
  • Laravel Herd and Docker still work, if you use them

How it works

  1. 1Open a project.
  2. 2Coodoo sees what it needs, from files such as package.json or composer.json.
  3. 3What is missing is installed from the official source and checked.
  4. 4Your app starts with the right versions, and its database is ready.

On Mac and Windows

It works on macOS and Windows. On Windows, PHP needs the Microsoft Visual C++ Runtime, which most PCs already have; if it is missing, Coodoo says where to get it.

Frequently asked questions

Does Coodoo change my computer?

No. Everything goes into Coodoo’s own folder and only Coodoo uses it. Your PATH and your own terminal stay as they are.

Do I need Laravel Herd or Docker?

No. Coodoo installs PHP, Composer and the databases itself. If you already use Herd or Docker, Coodoo works with them.

Where do the programs come from?

From fixed, known sources such as nodejs.org, Eclipse Temurin, python-build-standalone, static-php-cli, windows.php.net, mysql.com and Maven Central, each download checked with a checksum.
