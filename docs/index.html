You don't need to be a programmer. Write what you want in plain language, such as "A login page with email and password". Coodoo turns it into a plan, builds it step by step, checks its own work and keeps your code safe on GitHub. Every screen explains what a button does before you press it. Je hoeft geen programmeur te zijn. Schrijf in gewone taal wat je wilt, bijvoorbeeld "Een inlogpagina met e-mail en wachtwoord". Coodoo maakt er een plan van, bouwt het stap voor stap, controleert zijn eigen werk en bewaart je code veilig op GitHub. Elk scherm legt uit wat een knop doet voordat je erop drukt.

Safety rules that are always onVeiligheidsregels die altijd aan staan

The agents work on their own. Within hard limits.De agents werken zelfstandig. Binnen harde grenzen.

No goal, agent or button can switch these off.Geen doel, agent of knop kan deze uitzetten.

✓Your repository stays.Je repository blijft. Never deleted, archived, transferred or made public.Nooit verwijderd, gearchiveerd, overgedragen of openbaar gemaakt.
✓History is never rewritten.Geschiedenis wordt nooit herschreven. No force pushes, no deleted branches or tags.Geen force-push, geen verwijderde branches of tags.
✓Keys stay secret.Sleutels blijven geheim. Encrypted, never shown, never committed.Versleuteld, nooit getoond, nooit gecommit.
✓The agents can't reach your login.De agents kunnen niet bij je login. They only write inside your project folder.Ze schrijven alleen in je projectmap.
✓Commits in your name.Commits op jouw naam. Never in the AI's.Nooit op naam van de AI.
✓Work follows your flow.Werk volgt je flow. No step is ever skipped.Er wordt nooit een stap overgeslagen.
