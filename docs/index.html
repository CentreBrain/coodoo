Say what you want. Together you turn it into a goal.Zeg wat je wilt. Samen maak je er een doel van.

You don't need to be a programmer. Describe what you want in your own words; the agent asks what it needs to know and proposes a goal. One click puts it in the queue.Je hoeft geen programmeur te zijn. Beschrijf in je eigen woorden wat je wilt; de agent vraagt wat hij moet weten en stelt een doel voor. 02

One AI builds. The other checks. Then it looks at your app.De ene AI bouwt. De andere controleert. Dan kijkt hij naar je app.

Every task is reviewed by the other agent before it's committed. After that Coodoo starts your app and looks at it, like a person would. Broken or unsafe? It goes back to the developer first.Elke taak wordt door de andere agent gereviewd voordat hij wordt gecommit. Daarna start Coodoo je app en bekijkt hem, zoals een mens zou doen. Kapot of onveilig? Dan gaat het eerst terug naar de ontwikkelaar.

  • Security problems are fixed before anything elseBeveiligingsproblemen worden eerst opgelost
  • Lessons from rejected work are remembered next to the codeLessen uit afgekeurd werk worden bij de code onthouden

03

Neat on GitHub. Nothing reaches main untested.Netjes op GitHub. Niets komt ongetest op main.

The autopilot works on the first branch of your flow. With Promote the work moves one step on, through a pull request where GitHub asks for one, waiting for the checks. Every commit is in your name, never in the AI's.De autopilot werkt op de eerste branch van je flow. Met Promote gaat het werk een stap verder, via een pull request waar GitHub daarom vraagt, en wachtend op de checks. Elke commit staat op jouw naam, nooit op die van de AI.

The agents work on their own. Within hard limits.De agents werken zelfstandig. Binnen harde grenzen.

These rules are always on. No goal, agent or button can switch them off; Coodoo stops whatever tries.Deze regels staan altijd aan. Geen doel, agent of knop kan ze uitzetten; Coodoo houdt tegen wat het toch probeert.

✓Your repository stays.Je repository blijft. Never deleted, archived, transferred or made public.Nooit verwijderd, gearchiveerd, overgedragen of openbaar gemaakt.
✓History is never rewritten.Geschiedenis wordt nooit herschreven. No force pushes, no deleted branches or tags.Geen force-push, geen verwijderde branches of tags.
✓Keys stay secret.Sleutels blijven geheim. Encrypted, never shown, never committed.Versleuteld, nooit getoond, nooit gecommit.
✓The agents can't reach your login.De agents kunnen niet bij je login. They only write inside your project folder.Ze schrijven alleen in je projectmap.
✓Commits in your name.Commits op jouw naam. Never in the AI's.Nooit op naam van de AI.
✓Work follows your flow.Werk volgt je flow. No step is ever skipped.Er wordt nooit een stap overgeslagen.
