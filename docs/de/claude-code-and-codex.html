Claude Code und Codex als Team. Ohne Terminal.

Claude Code und Codex sind leistungsstarke KI-Coding-Agenten, gemacht fürs Terminal. Coodoo lässt sie für dich zusammenarbeiten, mit Zielen, einem Autopiloten, Reviews, GitHub und Sicherheitsregeln drumherum.

Was Coodoo hinzufügt

Allein warten die Agenten in einem Terminal auf deinen nächsten Befehl, und um Git, Tests und Sicherheit kümmerst du dich selbst. Coodoo macht aus ihnen ein Team, mit dem du in einfachen Worten sprichst.

  • Ein Chat in einfachen Worten statt Terminal-Befehlen
  • Zwei Agenten, die die Arbeit des anderen prüfen
  • Ein Autopilot, der Ziele und Aufgaben abarbeitet
  • Branches, Pull Requests und Releases, alles geregelt
  • Sicherheitsregeln, die immer aktiv sind

Nicht enthalten: dein KI-Abo

Coodoo ist nicht von Anthropic oder OpenAI und enthält deren Dienste nicht. Du nutzt dein eigenes Abo bei Anthropic (Claude) und/oder OpenAI (ChatGPT), zu deren Bedingungen.

Häufige Fragen

Ist Coodoo von Anthropic oder OpenAI?

Nein. Coodoo wird von CentreBrain entwickelt und ist nicht mit Anthropic oder OpenAI verbunden.

Welches Abo brauche ich?

Claude (Pro oder Max) für Claude Code und/oder ChatGPT (Plus oder Pro) für Codex. Eines reicht; mit beiden baut das eine und das andere prüft.

Kann ich Claude Code und Codex weiterhin selbst nutzen?

Ja. Coodoo nutzt die normalen Programme, also kannst du sie auch weiter in deinem eigenen Terminal verwenden.
