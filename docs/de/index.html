Die Agenten arbeiten selbstständig. Innerhalb fester Grenzen.

Diese Regeln sind immer aktiv. Kein Ziel, kein Agent und kein Knopf kann sie abschalten; Coodoo stoppt alles, was es versucht.

✓Dein Repository bleibt. Nie gelöscht, archiviert, übertragen oder öffentlich gemacht.
✓Der Verlauf wird nie umgeschrieben. Keine Force-Pushes, keine gelöschten Branches oder Tags.
✓Schlüssel bleiben geheim. Verschlüsselt, nie angezeigt, nie committet.
✓Die Agenten kommen nicht an deinen Login. Sie schreiben nur in deinen Projektordner.
✓Commits auf deinen Namen. Nie auf den der KI.
✓Die Arbeit folgt deinem Flow. Kein Schritt wird je übersprungen.

Häufige Fragen

Sind Claude und ChatGPT enthalten?

Nein. Coodoo ist das Team rund um die KI: die Ziele, der Autopilot, die Reviews, GitHub und die Sicherheitsregeln. Die KI selbst kommt aus deinem eigenen Abo bei Anthropic (Claude Pro oder Max, für Claude Code) und/oder OpenAI (ChatGPT Plus oder Pro, für Codex). Dieses Abo schließt du selbst ab und bezahlst es selbst; es ist nicht Teil der Coodoo-Lizenz.

Muss ich programmieren können?

Nein. Du beschreibst in einfachen Worten, was du willst, und das KI-Team baut es. Du brauchst kein Terminal. Es hilft aber, dir anzusehen, was das Team erstellt, bevor du es nutzt.

Brauche ich sowohl Claude als auch ChatGPT?

Eines reicht. Mit beiden baut ein Agent und der andere prüft seine Arbeit. So werden mehr Fehler gefunden.

Wo liegt mein Code?

Auf deinem eigenen Computer und in deinem eigenen GitHub-Konto. Coodoo läuft auf deinem Computer; CentreBrain speichert deinen Code nicht. Was die Agenten lesen, wird an den KI-Dienst gesendet, den du nutzt (Anthropic oder OpenAI), zu dessen Bedingungen.

Auf welchen Computern läuft Coodoo?

macOS (Apple silicon und Intel) und Windows (x64 und ARM).

Ist es sicher, KI selbstständig arbeiten zu lassen?

Coodoo hat Sicherheitsregeln, die immer aktiv sind: Dein Repository wird zum Beispiel nie gelöscht, der Verlauf nie umgeschrieben, und deine Schlüssel bleiben geheim. Sie begrenzen die Risiken, können sie aber nicht ausschließen: KI kann Fehler machen. Lies den Haftungsausschluss und die Risiken von KI.
