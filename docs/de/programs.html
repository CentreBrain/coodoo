Sprachen und Datenbanken, ohne Installationsaufwand.

Node.js, Python, Java, PHP, MySQL und PostgreSQL: Coodoo installiert die Versionen, die dein Projekt braucht, in einem eigenen Ordner, mit Prüfsumme kontrolliert und ohne Admin-Passwort. Auf dem Rest deines Computers ändert sich nichts.

Alles in Coodoo

Ein bisschen wie Docker, nur ohne Container: Die Programme liegen in einem eigenen Ordner von Coodoo, und nur Coodoo nutzt sie. Die Agenten, das Terminal in Coodoo und deine laufende App bekommen die richtige Version, und deine eigene Einrichtung bleibt, wie sie war.

  • Versionen wählen, etwa PHP 8.4 oder Node 22, und einen Standard pro Sprache
  • Patches werden täglich geprüft und von selbst installiert
  • Laravel ohne Laravel Herd: PHP und Composer inklusive
  • Eigenes MySQL und PostgreSQL von Coodoo, mit einer Datenbank pro Projekt
  • Laravel Herd und Docker funktionieren weiterhin, wenn du sie nutzt

So funktioniert es

  1. 1Öffne ein Projekt.
  2. 2Coodoo erkennt, was es braucht, an Dateien wie package.json oder composer.json.
  3. 3Was fehlt, wird aus der offiziellen Quelle installiert und geprüft.
  4. 4Deine App startet mit den richtigen Versionen, und ihre Datenbank ist bereit.

Auf Mac und Windows

Es funktioniert auf macOS und Windows. Unter Windows braucht PHP die Microsoft Visual C++ Runtime, die die meisten PCs schon haben; fehlt sie, sagt Coodoo dir, wo du sie bekommst.

Häufige Fragen

Verändert Coodoo meinen Computer?

Nein. Alles kommt in einen eigenen Ordner von Coodoo, und nur Coodoo nutzt ihn. Dein PATH und dein eigenes Terminal bleiben, wie sie sind.

Brauche ich Laravel Herd oder Docker?

Nein. Coodoo installiert PHP, Composer und die Datenbanken selbst. Wenn du Herd oder Docker schon nutzt, arbeitet Coodoo damit.

Woher kommen die Programme?

Aus festen, bekannten Quellen wie nodejs.org, Eclipse Temurin, python-build-standalone, static-php-cli, windows.php.net, mysql.com und Maven Central. Jeder Download wird mit einer Prüfsumme kontrolliert.
