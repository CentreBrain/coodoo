Todo dentro de Coodoo

Un poco como Docker, pero sin contenedores: los programas viven en la carpeta propia de Coodoo y solo Coodoo los usa. Los agentes, el terminal de Coodoo y tu app en marcha reciben la versión correcta, y tu propia configuración se queda como estaba.

  • Elige versiones, como PHP 8.4 o Node 22, y una estándar por lenguaje
  • Parches comprobados cada día e instalados solos
  • Laravel sin Laravel Herd: PHP y Composer incluidos
  • MySQL y PostgreSQL propios de Coodoo, con una base de datos por proyecto
  • Laravel Herd y Docker siguen funcionando, si los usas

Cómo funciona

  1. 1Abre un proyecto.
  2. 2Coodoo ve lo que necesita a partir de archivos como package.json o composer.json.
  3. 3Lo que falta se instala desde la fuente oficial y se comprueba.
  4. 4Tu app se inicia con las versiones correctas y su base de datos está lista.

En Mac y Windows

Funciona en macOS y Windows. En Windows, PHP necesita el Microsoft Visual C++ Runtime, que la mayoría de los PC ya tienen; si falta, Coodoo te dice dónde conseguirlo.

Preguntas frecuentes

¿Coodoo cambia mi ordenador?

No. Todo va a la carpeta propia de Coodoo y solo Coodoo lo usa. Tu PATH y tu propio terminal se quedan como están.

¿Necesito Laravel Herd o Docker?

No. Coodoo instala él mismo PHP, Composer y las bases de datos. Si ya usas Herd o Docker, Coodoo trabaja con ellos.

¿De dónde vienen los programas?

De fuentes fijas y conocidas, como nodejs.org, Eclipse Temurin, python-build-standalone, static-php-cli, windows.php.net, mysql.com y Maven Central. Cada descarga se comprueba con una suma de verificación.
