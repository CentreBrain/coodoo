How it works

  1. 1A goal gets its own branch.
  2. 2Each approved task is committed there in your name.
  3. 3The finished goal is combined, tested and reviewed, and goes to development.
  4. 4You promote it to staging and main, through the checks of your flow.

No Git knowledge needed

You don’t have to know what a branch or a merge is. Coodoo explains what happens in plain words, and asks you only when a decision is yours, such as before something goes to main.

Frequently asked questions

Do I need to know Git?

No. Coodoo handles branches, commits and pull requests for you.

Can I use an existing repository?

Yes. Open or clone a repository you already have; Coodoo works with it as it is.

What if I work on two computers?

Get the latest work on the other computer with one click. An agent checks both sides first, so nothing is lost.
